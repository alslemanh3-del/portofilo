# Portfolio - [اكتب اسمك هنا]

مرحباً بك في مستودع ملفي الشخصي (Portfolio)! 
هذا المشروع عبارة عن موقع ويب تم تصميمه وبناؤه لعرض مهاراتي، مشاريعي، وخبراتي في مجال تطوير الويب.

## 🚀 المميزات
- **تصميم متجاوب (Responsive):** يعمل بشكل ممتاز على جميع الأجهزة (الجوال، التابلت، الكمبيوتر).
- **الوضع الليلي (Dark Mode):** تصميم عصري بألوان مريحة للعين.
- **حركات وأنيميشن (Animations):** تأثيرات حركية عند التمرير (Scroll Reveal) وحركات ناعمة عند تمرير الماوس.
- **أقسام كاملة:** يحتوي على الهيرو، المشاريع، الخدمات، الخبرات، وطرق التواصل.

## 🛠️ المهارات والتقنيات المستخدمة
- **HTML5:** لبناء هيكل الصفحة.
- **CSS3:** للتنسيقات، الألوان، والتأثيرات الحركية.
- **JavaScript:** لإضافة تفاعلية الحركة عند التمرير.
